## Types:
Manual Acceptance Testing

## Processes:
The designer and PM will do acceptance testing as soon as pull request is opened.

## Environment:
Acceptance testing will be done in the preview stage of a vercel deployment, using the code in the pull request branch. They will use modern browsers such as FireFox or Safari to test.

## Failure protocal:
If acceptance testers find an error in the deployment, a comment will be made on the pull request for changes to be made. The developer working on that pull request will work on the error found by the acceptance tester.
